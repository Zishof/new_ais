# AIS Next v0.1.0-uat.1

- Tanggal: 4 September 2026
- Kanal: UAT prerelease
- Target: localhost dan database clone terisolasi

## Ringkasan

`v0.1.0-uat.1` adalah paket UAT pertama AIS Next yang menyatukan foundation arsitektur, migrasi
read-only bertahap, satu kandidat master-data CRUD, UI/UX responsif, dan bukti teknis Fase 0–7.
Rilis ini menjaga AIS Legacy tetap beroperasi dan tidak mengizinkan retirement route apa pun.

Rilis ini **bukan** persetujuan produksi. Route normal `local` untuk Organization, Attendance,
Academic, Supporting ERP, dan Finance tetap Legacy-owned; kandidat Next domain tersebut hanya
aktif pada tenant clone `uat-local`.

## Isi rilis

### Platform dan arsitektur

- Modular monolith Java 25 dengan batas Spring Modulith/ArchUnit.
- Trusted-host tenant resolution dan bounded lazy CORE/FILE data-source pools.
- Control-plane PostgreSQL terpisah untuk tenant, domain, route ownership, nonce, audit, outbox,
  dan file saga.
- Signed one-time authentication handoff dengan issuer, audience, tenant, role, expiry, dan replay
  protection.
- Exact route ownership, write ownership, fail-closed authorization, rollback, dan retirement gate.
- Problem Details, OpenAPI, metrics, health probes, request ID, dan structured audit boundary.
- CycloneDX SBOM serta dependency/license policy pada build.

### Domain dan route

| Fase | Kandidat | Route utama | Mode UAT |
|---|---|---|---|
| 2 | Identity/RBAC | `/roles`, `/profile`, `/search`, `/dashboard` | Next read-only |
| 3 | Jenis sekolah | `/school-types` | Next write pada clone |
| 4 | Kehadiran harian | `/attendance/daily` | Next read-only pada clone |
| 5 | Direktori siswa | `/academic/students` | Next read-only pada clone |

| 7 | Grup akun keuangan | `/finance/account-groups` | Next read-only pada clone |

Setiap UI memiliki pasangan API `/api/v1`. Detail field, filter, paging, authorization, ownership,
dan recovery berada di baseline serta evidence masing-masing fase.

### UI/UX

- Public entry modern dengan satu CTA resmi menuju login AIS Legacy.
- Dashboard role-aware yang menampilkan tenant, user, active role, session state, dan service cards.
- Desktop navigation dua tingkat dan full-width collapsible mobile navigation.
- Breadcrumb serta active-route state otomatis.
- Shared form, filter, table, empty state, status, total, dan financial safety notice.
- Visible keyboard focus, skip link, semantic landmarks, reduced motion, print behavior, dan
  high-contrast palette.
- Seluruh Tabler/CSS/JavaScript penting di-self-host agar runtime tidak bergantung pada CDN.

## Keamanan dan database

- Flyway hanya menulis ke `ais_next_control`.
- Source `ais` dan `streaming_ais` tidak menerima migration, DDL, user UAT, menu grant, maupun
  business fixture dari rilis ini.
- UAT write dijalankan hanya pada clone bernama eksplisit dan selalu disertai cleanup.
- Student projection mengecualikan credential, contact/parent, health, dan financial fields.
- Finance slice hanya memuat ID, nama, dan keterangan grup; tidak ada saldo, jurnal, posting,
  pembayaran, approval, closing, atau reconciliation operation.
- Secret database dan handoff tidak terdapat dalam source, dokumentasi, SBOM, atau nama artefak.

## Menjalankan rilis

```powershell
$env:AIS_CONTROL_DB_USERNAME = '<control-user>'
$env:AIS_CONTROL_DB_PASSWORD = '<control-password>'
$env:AIS_LOCAL_DB_USERNAME = '<legacy-read-user>'
$env:AIS_LOCAL_DB_PASSWORD = '<legacy-read-password>'
$env:AIS_HANDOFF_SIGNING_KEY = '<minimum-32-byte-random-secret>'

java -jar .\ais-next-web-0.1.0-uat.1.jar
```

Konfirmasi `GET /actuator/health` menghasilkan status `UP`, landing page dapat dibuka, dan host UAT
resolve ke tenant clone yang tepat sebelum menerbitkan token handoff.

## Upgrade dan kompatibilitas

Ini adalah prerelease pertama sehingga tidak ada migrasi aplikasi dari versi AIS Next sebelumnya.
Control-plane Flyway tetap pada migration yang tervalidasi dan idempotent. Schema Legacy tidak
diubah. AIS Legacy harus tetap tersedia untuk login dan seluruh route yang belum dipromosikan.

## Rollback

1. Hentikan hanya proses AIS Next dari rilis ini.
2. Pastikan route yang diuji kembali ke `LEGACY`/ownership sebelumnya menggunakan
   [`docs/runbooks/route-rollback.md`](../runbooks/route-rollback.md).
3. Pertahankan AIS Legacy dan database sumber; jangan menghapus route atau data sebagai rollback.
4. Jika control-plane bermasalah, pulihkan hanya `ais_next_control` dari backup yang terpisah.
5. Simpan log yang sudah meredaksi token serta catat artifact checksum, route state, dan waktu
   rollback.

## Batasan dan gate terbuka

- UI belum membawa seluruh shortcut, widget bantuan, dan modul operasional Legacy.
- Organization CRUD belum production-approved walaupun clone UAT lulus.
- Attendance source snapshot kosong; non-empty behavior dibuktikan hanya dengan fixture clone.
- Academic, library, dan finance baru berupa proyeksi minimum read-only.
- Belum ada target-environment load/performance evidence.
- Domain-owner, independent security/privacy/reconciliation, operations, retention/restore, dan
  rollback-window approval belum lengkap.
- Production traffic dan unknown-consumer disposition belum tersedia; tidak ada Legacy route yang
  dapat di-retire.

## Keputusan promosi

Gunakan prerelease ini hanya untuk technical/business UAT yang terkontrol. Promosikan route satu
per satu setelah gate roadmap terkait memiliki bukti bertanggal. Jangan mengubah label prerelease
menjadi production release tanpa keputusan baru dan artefak baru yang dibangun dari tag produksi.
